# NEOROVO Content Studio

نسخه اولیه و آزمایشی پنل فارسی مدیریت محتوای NEOROVO.

## امکانات فعلی
- رابط فارسی و راست‌چین، سازگار با موبایل
- ساخت پیش‌نویس سناریوی ریلز با قالب‌های داخلی
- نمایش گویندگی، زمان‌بندی صحنه‌ها، پرامپت تصویری و کپشن پیشنهادی
- آرشیو پیش‌نویس‌ها با وضعیت «در انتظار بررسی» و «تأییدشده»
- ذخیره اطلاعات در حافظه مرورگر (localStorage)

## محدودیت‌های مهم
- این نسخه به اینستاگرام یا API متا متصل نیست.
- تأیید محتوا فقط وضعیت پیش‌نویس را تغییر می‌دهد و هیچ چیزی منتشر نمی‌کند.
- سناریوها قالب اولیه هستند؛ ادعاها و اطلاعات باید پیش از انتشار راستی‌آزمایی شوند.
- اطلاعات فعلاً فقط در همان مرورگر و دستگاه ذخیره می‌شوند؛ پاک شدن داده‌های مرورگر می‌تواند آن‌ها را حذف کند.
- برای استفاده از فونت Vazirmatn اتصال اینترنت لازم است؛ فونت جایگزین نیز تعریف شده است.

## انتشار رایگان با GitHub Pages
1. وارد Settings مخزن شوید.
2. از منوی Pages، در بخش Build and deployment گزینه Deploy from a branch را انتخاب کنید.
3. Branch را روی main و پوشه را روی /(root) بگذارید و Save کنید.
4. پس از آماده شدن، نشانی سایت در همان بخش Pages نمایش داده می‌شود.

این پروژه یک نمونه اولیه است و هیچ سرویس پولی یا کلید محرمانه‌ای نیاز ندارد.

## اتصال رسمی اینستاگرام (در حال آماده‌سازی)
- پنل فعلی هنوز اتصال فعال Instagram ندارد و هیچ محتوایی را منتشر نمی‌کند.
- اتصال واقعی باید با OAuth رسمی Meta و سرویس سمت سرور انجام شود؛ توکن و App Secret نباید در مرورگر یا مخزن عمومی ذخیره شوند.
- حساب هدف باید Professional (Creator یا Business) باشد و مجوزهای لازم Meta تأیید شوند.
- قابلیت‌های هدف: انتشار محتوا، دریافت Insights، مدیریت کامنت‌ها و پیام‌ها در چارچوب محدودیت‌ها و سیاست‌های Meta.
- هیچ قابلیت لایک/فالو/آنفالو انبوه یا ارسال اسپم پیاده‌سازی نمی‌شود.


## راه‌اندازی مرحله‌ای اتصال رسمی اینستاگرام
در پنل، بخش «مرکز اتصال رسمی اینستاگرام» اکنون یک راهنمای چهارمرحله‌ای دارد:
1. بررسی نوع حساب و ثبت وضعیت Personal / Creator / Business.
2. معرفی مسیر پیشنهادی Instagram API with Instagram Login.
3. چک‌لیست برنامه Meta، محصول Instagram Login، نشانی بازگشت OAuth و سرویس سمت سرور.
4. نمایش پیشرفت آماده‌سازی در همان مرورگر.

### نکات فنی و امنیتی
- حساب‌های Personal از API حرفه‌ای اینستاگرام پشتیبانی نمی‌شوند؛ حساب باید Creator یا Business باشد.
- برای NEOROVO که برند تولید محتواست، Creator پیشنهاد اولیه است؛ Business نیز قابل پشتیبانی است.
- مسیر Instagram Login برای حساب حرفه‌ای معمولاً به اتصال Facebook Page نیاز ندارد. مسیر Facebook Login پیش‌نیاز جداگانه دارد.
- چک‌لیست و انتخاب نوع حساب فقط در localStorage همین مرورگر ذخیره می‌شوند؛ این اطلاعات به سرور ارسال نمی‌شوند و بین دستگاه‌ها همگام نیستند.
- این نسخه هنوز OAuth، callback، token exchange، ذخیره امن توکن، webhook یا انتشار واقعی را پیاده‌سازی نکرده است. GitHub Pages محل نگهداری امن App Secret یا Access Token نیست.
- تا قبل از راه‌اندازی backend امن و تست OAuth، نباید وضعیت «متصل» نمایش داده شود.
- مستندات: https://developers.facebook.com/docs/instagram/platform/ و https://developers.facebook.com/apps/
